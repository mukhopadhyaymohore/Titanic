# 🚢 Data Storytelling: Survival on the Titanic

## Overview
Analysis of the Titanic - Machine Learning from Disaster dataset told through 3 data story arcs, 
plus an interactive terminal-based survival predictor.

## Story Arcs
- 📊 **Arc 1 — Class vs. Conscience** — Did your ticket price determine your fate?
- 👩‍👧 **Arc 2 — Women & Children First** — Was the maritime rule actually followed?
- 🎩 **Arc 3 — What's in a Name?** — Did your social title seal your fate?
- 🎮 **Bonus — Interactive Predictor** — Would you have survived?

## Tech Used
Python · Pandas · Matplotlib · Seaborn · Scikit-learn

## Model Accuracy
Random Forest Classifier — **79.9%** on held-out test set
